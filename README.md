# Bastion Recipes

Version: 5.0

Minecraft: 26.3

A vanilla data pack that adds crafting, cooking and stonecutter recipes for items that are unobtainable or hard to farm in survival (elytra, Nether star, trident, saddle, horse and nautilus armor, coral blocks…), plus a few "uncrafting" recipes.

No vanilla recipe is changed or removed: the data pack only adds new ones.

## Recipes

Grid legend: each group is one row of the crafting table, `·` = empty slot. Recipes without a grid are shapeless (ingredient order doesn't matter).

## 📥 Installation

Like any data pack: drop the downloaded folder into `.minecraft/saves/<your_world>/datapacks/` (or `<server>/world/datapacks/` on a server), then run `/reload` or restart the world.
